# Bloom-Tweaks

An extension to resolve [Bloom Theme](https://github.com/nimsandu/spicetify-bloom) issues.


#### Spotify Version:
```
1.2.60.564
```

#### Spicetify Version:
```
v2.45.3
```

### Steps

1. Download [bloomTweaks.js](https://github.com/Amiru2007/Bloom-Tweaks/blob/main/bloomTweaks.js) file.
2. Navigate to the Spicetify's `Extensions` directory.
3. Paste the `.js` file into the folder.
4. Download & install supported Spotify version.
5. Open Windows Poweshell then run
```
spicetify backup apply
spicetify spotify-updates block
```
